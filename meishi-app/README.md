# 名刺自動作成（Illustrator スクリプト）— 試作版

注文通知アプリ（楽天・Yahoo! の注文メールを表示するアプリ）で注文を選んで［名刺を作成］を押すと、
選んだデザインの `.ai` に注文内容（名前・肩書・住所など）を流し込み、別名で保存して Illustrator で開きます。

> ⚠ このリポジトリは **公開（public）** です。お客さんの情報やデザインの `.ai`、
> 注文通知アプリ本体（メールのパスワード入り）はここに入れないでください。

## なぜ Illustrator のスクリプトなのか

`.ai` ファイルの中身は Illustrator 独自の形式で、Illustrator 以外のソフトで書き換えると
レイアウトやフォントが崩れます。そこで **Illustrator 自身に作業させるスクリプト（.jsx）** にしました。
CS6 から最新版まで動くように作っています。

## 使い方（注文通知アプリの［名刺を作成］ボタン）

1. 注文一覧で注文を選ぶ（command キーを押しながらクリックで複数選択）→［名刺を作成］
2. 注文ごとに「○○様のデザイン .ai を選んでください」と出るので、使うテンプレートを選ぶ
   （前回選んだフォルダから始まります。キャンセルした注文は作りません）
3. Illustrator が前面に出て、テンプレートに注文内容を流し込み、次の名前で **別名保存して開いたまま** にします

   `~/Library/CloudStorage/Dropbox/1名刺表札作業用/1_新規ai/注文番号_名刺の氏名_注文者氏名.ai`

   - 名刺の氏名がなければ会社名を使います
   - Yahoo! は注文者名がないので `注文番号_名刺の氏名.ai`
   - 同じ名前のファイルがあれば `_2` `_3` を付けます（上書きしません）
4. 確認してほしいこと（差し込み先がない項目、自由記入、備考、LOGO 横のマークを消したことなど）が
   あれば、最後に Illustrator にまとめて表示されます

> 初めて Illustrator を呼び出すとき、Mac が「“注文通知”から“Adobe Illustrator”を制御しようとしています」
> と聞いてくるので［OK］を押してください。

### 注文通知アプリへの組み込み

注文通知アプリのフォルダに `mail/meishi_export.py`・`meishi_job.jsx`・`meishi_ai.jsx`・`meishi_core.jsx` を入れ、
`build_app.sh` でアプリを作り直します（`build_app.sh` に4つをコピーする行を追加済み）。
保存先を変えるときは `meishi_export.py` の `OUTPUT_DIR` を書き換えます。

### メールから取り出す項目

会社名、部署名、肩書き、お名前、ふりがな（ローマ字なら英字氏名）、〒、住所、TEL、FAX、Mobile、E-mail、WEB、
ロゴデータ、N行目（自由記入）、備考。名刺に入れない情報（自由記入・備考など）は「確認してほしいこと」に表示します。

### LOGO の扱い

- ロゴデータ **無し**：`LOGO` の文字を会社名に置き換え、LOGO のすぐ横（上下左右）にある **ロゴマークの画像を消します**。
  LOGO の文字とグループになっている図形も、すぐ横にあれば消します
- ロゴデータ **有り**：`LOGO` もマークもそのまま（あとでロゴに差し替え）

## CSV からまとめて作る（予備の方法）

`meishi_auto.jsx` を［ファイル］→［スクリプト］→［その他のスクリプト...］で実行すると、
デザイン番号入りの CSV（見本は `sample/注文データ_サンプル.csv`）からまとめて作れます。
テンプレートフォルダ内の「デザイン番号.ai」を使い、結果を `処理結果_日時.txt` に書き出します。

## 注文CSVの形

1行目が見出し、2行目から1注文1行です。列の順番は自由で、使わない列は空欄でかまいません。

| 見出し | 例 | 置き換わる場所（テンプレート内の仮の文字） |
|---|---|---|
| 注文番号 | 123456-20261006-0000000001 | （ファイル名に使用） |
| デザイン番号 | business008 | テンプレートフォルダ内の `business008.ai` を使用 |
| 肩書 | 代表取締役 | `代表取締役` |
| 部署 | 営業部 | 肩書の前に付きます（営業部　部長） |
| 氏名 | 山田 太郎 | `鈴　木　太　郎` など（1文字ずつ空いていれば同じ空け方に） |
| 郵便番号 | 100-0005 | `〒000-0000` |
| 住所1 / 住所2 | 東京都千代田区… / ○○ビル5F | `○○○県○○市○○町00-00-0` / `○○○○○000号` |
| TEL / FAX / 携帯 | 03-1234-5678 | `Tel :` `Fax :` `Mobile:` の後ろ |
| メール / URL | taro@example.co.jp | `E-mail :` の後ろ、`http://…` |
| 会社名 + ロゴデータ | 株式会社サンプル / 無し | ロゴデータが「無し」なら `LOGO` が会社名に。「有り」なら LOGO はそのまま（要確認に表示） |
| 氏名英字 / 肩書英字 / 会社名英字 | Taro Yamada / President | 英語面の `Ichiro Suzuki` / `President` / `artcode` |
| 英字住所1 / 英字住所2 | 1-2-3 Marunouchi, … | 英語面の住所2行 |

- **空欄の項目は、その行ごと消えます**（FAX がない人は「Fax :」の行がなくなる）
- 見出しの別名（「受注番号」「お名前」「電話番号」など）も読めます。追加は `meishi_core.jsx` の `FIELD_ALIASES`
- Excel で保存した CSV（Shift_JIS）でも「CSV UTF-8」でも読めます

## テンプレート側のルール

スクリプトは、テンプレートに入っている **仮の文字**（`鈴木太郎`、`○○○県…`、`000-000-0000` など）を探して置き換えます。

- 新しい仮の文字を使ったテンプレートがあれば、`meishi_core.jsx` の `PLACEHOLDERS` に1行足します
- どうしても自動で見つからないテキストは、Illustrator のレイヤーパネルでテキストの名前を
  **項目名（例：`氏名`）に変える**と、そのテキストの中身を丸ごと置き換えます
- `.ai` は「PDF互換ファイルを作成」にチェックを入れて保存してください（検査ツールで中身を読むため）

## 開発者向け

```sh
node test/test_core.js                       # 置き換えロジックのテスト（Illustrator不要）
node test/test_ai_mock.js                    # Illustrator の書き換え部分をニセの書類でテスト
python3 mail/test_meishi_export.py           # メール→名刺データ変換のテスト
pip install pymupdf
python tools/scan_templates.py テンプレートフォルダ > templates.json
node tools/scan_report.js templates.json > report.md   # 全テンプレートの差し込み先・消えるLOGOマーク・⚠の一覧
```
